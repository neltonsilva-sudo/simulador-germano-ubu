# Simulador do Complexo Germano–Ubu

Simulador 3D didático do processo produtivo de minério de ferro (mina, concentração, mineroduto, pelotização e porto).

- O simulador roda no navegador (Three.js).
- IA, previsão do tempo, inspeções e controle de acesso ficam no servidor (Google Apps Script) e exigem senha da sala de controle ou autorização pelo QR Code de uma área.
- Valores ilustrativos: modelo didático, não representa dados operacionais reais.
